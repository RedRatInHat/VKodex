# Архитектура

Этот документ описывает прежний контур на Codex SDK. Экспериментальное подключение
к задачам десктопа и его текущие ограничения описаны в [README](../README.md).

## Компоненты

| Каталог | Назначение |
| --- | --- |
| `src/platforms/vk` | Long Poll, сообщения, вложения и создание бесед |
| `src/core` | Команды, выбор сессий и запуск ходов |
| `src/core/ports` | Интерфейсы чата, агента и хранилища |
| `src/agents/codex` | Вызов Codex SDK и подготовка окружения процесса |
| `src/storage` | Хранение сессий в SQLite |
| `src/lib` | Работа с файлами, путями и текстом |

`src/index.ts` создаёт компоненты и передаёт входящие сообщения в `BotController`.
Контроллер проверяет отправителя, ищет сессию по `peer_id` и разбирает команды.
В управляющем чате выбор активной сессии хранится отдельно для каждой пары
`peer_id` и ID пользователя.

## Состояние

SQLite содержит настройки, сессии и выбор активной сессии. В записи сессии хранятся
workspace, создатель, ID беседы, ID потока Codex и статус. Архивирование удаляет
выбор этой сессии, но сохраняет её запись.

ID потока сохраняется после успешного возврата `CodingAgent.run`. Если первый ход
оборван или завершился ошибкой, обнаруженный ID не записывается в SQLite.

`TurnCoordinator` допускает один активный ход на сессию внутри процесса.
Блокировки не распределены между экземплярами бота; запускайте один экземпляр
на базу данных. Остановка процесса не возобновляет незавершённые ходы.

## Вложения

VK-адаптер проверяет отправителя до загрузки метаданных вложений. Контроллер
повторяет проверку и скачивает файлы в `.vkcodex/inbox/<turn-id>/`.
Изображения передаются как `local_image`, остальные файлы — путями в запросе.

Результаты берутся из `.vkcodex/outbox/<turn-id>/`. Бот ограничивает число и размер
файлов и пропускает символические ссылки при обходе. Содержимое файлов на наличие
секретов не проверяется. Изменённые исходники вне outbox автоматически не отправляются.

## Доступ

Список пользователей общий для бота. В управляющем чате нет отдельного ACL
для каждой сессии. Только владельцы могут создавать сессии; архивировать сессию
в её беседе может создатель или владелец.

`buildCodexEnvironment` передаёт выбранные системные переменные и явно разрешённые
дополнительные переменные. Переменные `VK_*` исключены; API-ключ передаётся SDK
отдельно. Эти меры не защищают секреты, которые лежат в доступном workspace.
