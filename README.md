# VKodex

Бот для запуска задач Codex через сообщения VK. Сессия связывает рабочий каталог,
поток Codex и, если VK разрешает её создать, отдельную беседу. Без отдельной беседы
сессии выбираются командой `/use` в управляющем чате.

Это прототип. Автоматические тесты не заменяют проверку Long Poll, загрузки файлов
и запуска Codex с реальными учётными данными.

## Запуск

Понадобятся актуальный выпуск Node.js 22 или 24, сообщество VK с сообщениями и Bots Long Poll
(`message_new`), токен сообщества с доступом к сообщениям и доступ к Codex.

```sh
npm install --global npm@11.12.1
npm ci
npm run check
```

Скопируйте `.env.example` в `.env` и заполните:

- `VK_GROUP_TOKEN`, `VK_GROUP_ID` — токен и ID сообщества;
- `VK_OWNER_IDS`, `VK_ALLOWED_USER_IDS` — ID пользователей через запятую;
  владельцы должны входить в список разрешённых пользователей;
- `WORKSPACE_ROOTS` — существующие корневые каталоги через запятую;
- `OPENAI_API_KEY` — ключ для Codex, если не используется сохранённая авторизация CLI.

Остальные настройки описаны в `.env.example`. Не храните `.env` внутри каталогов,
к которым даёте доступ через `WORKSPACE_ROOTS`.

```sh
npm run dev
```

Для запуска собранной версии: `npm run build`, затем `npm start`.

## Работа с ботом

Напишите сообществу `/bootstrap` с аккаунта владельца. Бот попробует создать
управляющую беседу `[VKodex] Main`. Затем отправьте:

```text
/new my-repository | Исправить экспорт
```

`my-repository` должен находиться внутри одного из `WORKSPACE_ROOTS`.
Если VK не разрешает создать управляющую беседу, владелец может использовать
личный диалог с ботом. Для работы без отдельных бесед задайте
`VK_CONVERSATION_MODE=single`.

| Команда | Где используется | Действие |
| --- | --- | --- |
| `/bootstrap` | Управляющий чат или личный диалог владельца | Создать главный чат |
| `/new <workspace> \| <title>` | Управляющий чат | Создать сессию (только владелец) |
| `/list` | Управляющий чат | Показать сессии |
| `/use <id>` | Управляющий чат | Выбрать сессию для текущего пользователя |
| `/status` | Управляющий чат или беседа сессии | Показать состояние |
| `/stop` | Отдельная беседа сессии | Остановить текущий ход |
| `/close` | Отдельная беседа сессии | Архивировать сессию |
| `/help` | Управляющий чат или беседа сессии | Показать справку |

Режимы `VK_CONVERSATION_MODE`:

- `managed` — ошибка создания беседы прерывает создание сессии;
- `single` — все сессии работают в управляющем чате;
- `auto` — попытаться создать беседу, а при ошибке оставить сессию в управляющем чате.

## Файлы и ограничения

Фотографии передаются Codex как изображения. Документы сохраняются в
`<workspace>/.vkcodex/inbox/<turn-id>/` и передаются по локальному пути.
Бот не распаковывает архивы.

Для ответа файлами Codex получает каталог `.vkcodex/outbox/<turn-id>/`.
Бот отправляет только файлы из этого каталога; лимиты числа и размера файлов
задаются в `.env`. Проверки содержимого на секреты перед отправкой нет.

Бот проверяет список разрешённых пользователей и расположение workspace.
Это не изоляция пользователей друг от друга: участники управляющего чата из
allowlist могут выбирать общие сессии. Используйте бот только с доверенными людьми.

По умолчанию заданы `workspace-write` и `never`. Интерактивные подтверждения
через VK не реализованы. Токен VK исключается из окружения, передаваемого Codex;
дополнительные переменные в `CODEX_ENV_ALLOWLIST` становятся доступны его процессу.
Не размещайте секреты в доступных ему каталогах.

В режиме `single` команды `/stop` и `/close` пока недоступны. ID потока Codex
сохраняется после успешного завершения хода; отмена или ошибка первого хода
не сохраняет этот ID.
