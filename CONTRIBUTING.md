# Разработка

Используйте актуальный выпуск Node.js 22 или 24 и npm 11.12.1,
как в CI и Docker. Установка и проверка:

```sh
npm install --global npm@11.12.1
npm ci
npm run check
```

`check` запускает TypeScript, тесты и сборку. Тесты используют подмены VK и Codex,
поэтому `.env` и доступ к API не нужны. Workflow `.github/workflows/ci.yml`
настроен на Windows/Linux с Node.js 22/24 и отдельную сборку Docker.
Для реальных интеграций есть `docs/SMOKE_TEST_RU.md`.

## Изменения

Работайте в отдельной ветке и открывайте pull request в `main`. Для крупных
изменений сначала опишите задачу в issue; мелкое исправление можно прислать сразу.
Один коммит должен решать одну понятную задачу.

Перед коммитом выполните `npm run check` и просмотрите `git diff --cached`.
В pull request укажите причину изменения, результаты проверок и риски для
существующих настроек и данных. Изменения поведения сопровождайте тестами.

При обновлении зависимостей коммитьте `package.json` и `package-lock.json` вместе.
Не прикладывайте `.env`, токены, данные сессий, вложения или логи с личными данными.

Настройки IDE и другие личные исключения добавляйте в `.git/info/exclude`.
Общий `.gitignore` предназначен для зависимостей, сборки, конфигурации и данных бота.
